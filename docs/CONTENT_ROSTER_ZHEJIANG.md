# Project Wildtrail — 浙江主题 25 只动物内容草案

> 版本：v0.3 placeholder  
> 用途：验证 Tier 1–5、位置玩法、生态标签和内容丰富度。  
> 这些 Tier 是游戏出现节奏，不代表现实中的动物强弱或保护价值。  
> 珍稀、受保护动物只使用“发现、观察、同行、返回栖息地”等表达。

---

## 1. Tier 节奏

| 回合 | 营地 Tier | 邂逅位 |
|---:|---:|---:|
| 1 | T1 | 3 |
| 2–3 | T2 | 3 |
| 4–5 | T3 | 4 |
| 6–7 | T4 | 4 |
| 8+ | T5 | 5 |

市场可出现不高于当前 Tier 的动物。具体权重放在 `campLevels.ts`，不得写入 UI。

升级合成后的固定奖励：

- 出现 3 个“当前营地 Tier + 1”的动物供选 1；
- T5 时改为 T5 发现或数据驱动的稀有奖励；
- 选择后可放到战斗位、替补位或替换现有单位；
- 所有安置路径都必须可取消或告别，不能卡死。

## 3. 设计限制

### 每只动物

- 一个主要技能；
- 一句可读说明；
- 最多一个主要触发；
- 数值按等级数组或明确公式；
- 不在 UI 里按 `speciesId` 特判；
- 位移效果统一使用 Board Mutation API；
- 营地效果统一使用 CampCommand/Effect API。

### Tier 5

Tier 5 不应简单地“数字特别大”。其差异优先来自：

- 改变位置；
- 利用环境；
- 改变触发顺序；
- 为整队提供可读的协作；
- 创造高光但有上限的连锁。

### 保护动物呈现

避免：

- 购买、售卖、捕捉、关笼；
- 以现实稀有程度直接标价；
- 让濒危动物成为纯粹战力商品。

推荐文案：

- 邂逅；
- 邀请同行；
- 观察；
- 建立默契；
- 返回栖息地；
- 完成图鉴记录。

## 4. 初始数值建议

不要一次追求平衡。先使用按 Tier 的窄区间：

| Tier | 基础攻击建议 | 基础体力建议 | 技能价值 |
|---:|---:|---:|---|
| 1 | 2–4 | 4–7 | 单次或低限次 |
| 2 | 3–5 | 4–8 | 明确小协同 |
| 3 | 4–6 | 5–9 | 位置/延迟/状态 |
| 4 | 5–7 | 6–11 | 强协同但有限制 |
| 5 | 6–9 | 7–13 | 高光机制，避免无条件碾压 |

合成等级的常驻攻体加成保留为内容数据，不写死在 engine：

```ts
levelGrowth: {
  attack: [0, 2, 5],
  health: [0, 2, 5],
}
```

不同动物未来可有自己的成长表，但原型阶段先统一。

## 5. 内容数据接口建议

```ts
interface AnimalDef {
  id: SpeciesId;
  nameZh: string;
  tier: 1 | 2 | 3 | 4 | 5;
  habitats: readonly Habitat[];
  baseAttack: number;
  baseHealth: number;
  levelGrowth: {
    attack: readonly [number, number, number];
    health: readonly [number, number, number];
  };
  ability: AbilityDef;
  iconKey: string;
  journal: {
    shortFact: string;
    regionNote: string;
    conservationTone?: "common" | "observeWithCare" | "protected";
  };
}
```

内容加载时运行 validator：

- ID 唯一；
- Tier 合法；
- 所有技能 selector 合法；
- Scale 长度正确；
- 不存在未知 effect；
- 中文描述非空；
- 不存在负基础体力；
- 受保护动物文案通过人工检查。
