## Known Bugs

- 10th win terminal flow can route back to battle because `phaseToScreen()` checks `pendingBattle` before `phase`.
- `finishBattleReport()` sets `successResolution` or `returnResolution` without clearing terminal `pendingBattle`.
- Success registration is still split across UI code instead of a pure domain `completeSuccessResolution()` transaction.
- Camp drag/drop and slot identity are still v0.2 architecture; P2 will replace them with fixed slots and atomic commands.
